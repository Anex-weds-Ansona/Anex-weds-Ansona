# Wedding Invitation Website

This project is a single-page wedding invitation inspired by your reference image.

## 1) Update invitation details

Open `index.html` and edit the `invitationDetails` object near the bottom of the file.

## 2) Preview locally

You can open `index.html` directly in your browser.

## 3) Publish to GitHub Pages

1. Create a new GitHub repository (for example: `wedding-invite`).
2. Upload all files from this `code` folder to that repository.
3. In GitHub repository settings, open **Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
5. Save, wait 1-2 minutes, then your URL will be:

`https://<your-github-username>.github.io/<repo-name>/`

Example:

`https://john-doe.github.io/wedding-invite/`

## Included files

- `index.html` - invitation content and editable details
- `styles.css` - visual style matching your reference card
- `assets/invitation-reference.jpeg` - source reference image used as floral frame
